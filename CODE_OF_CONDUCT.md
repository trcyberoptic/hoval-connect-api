# Code of Conduct

Short and simple:

- **Stay on topic.** This project is about an API and a Home Assistant
  integration — discussions are about the tech, not about people.
- **Be decent.** No insults, no hostility, no trolling, no publishing other
  people's private information.
- **Criticize the work, not the person.** Code review may be tough on the
  substance and stays fair in tone.
- **No politics.** Political, religious and other off-topic debates don't
  belong in issues, PRs or commits.

The maintainer has the final say and may remove violating content or block
accounts without further discussion.
